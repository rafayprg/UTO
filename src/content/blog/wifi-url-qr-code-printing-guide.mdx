## Understanding Reed-Solomon Error Correction

QR codes incorporate Reed-Solomon algebraic error correction to reconstruct data if the physical code is partially obscured, torn, stained, or viewed at an angle:

| Correction Level | Redundancy Capacity | Visual Module Density | Recommended Use Case |
| :--- | :--- | :--- | :--- |
| **Level L (Low)** | Approx 7% of data restorable | Lowest (largest modules) | Clean digital screens, short URLs |
| **Level M (Medium)** | Approx 15% of data restorable | Moderate (optimal balance) | Menus, business cards, mailers (Default) |
| **Level Q (Quartile)** | Approx 25% of data restorable | High | Industrial labels, retail packaging |
| **Level H (High)** | Approx 30% of data restorable | Dense (smallest modules) | Outdoor signage, harsh environments |

### The Density Tradeoff:
Higher error correction comes with a physical cost: it increases the number of black and white matrix squares (modules) required to encode the payload. A denser code requires higher camera resolution or larger physical print dimensions to scan reliably.

## The Physical Print Sizing Rule (10:1 Ratio)

To calculate the minimum physical dimensions for a printed QR code, apply the **10:1 Viewing Distance Formula**:

```text
Minimum Print Width = Expected Scanning Distance / 10
```

- **Restaurant Table Tent:** Scanned from 12 to 15 inches away -> Minimum width: **1.2 to 1.5 inches** (30 to 38 mm).
- **Wall Poster / Gallery Plaque:** Scanned from 3 to 4 feet away -> Minimum width: **3.5 to 4.8 inches** (90 to 120 mm).
- **Outdoor Billboard:** Scanned from 20 feet away -> Minimum width: **24 inches** (60 cm).

Printing below these optical thresholds forces smartphone cameras to macro-focus, leading to slow or failed detection.

## The Crucial Four-Module Quiet Zone

Surrounding the active data matrix is the **Quiet Zone**—a solid, unprinted white perimeter. The ISO/IEC 18004 standard mandates a quiet zone width of at least **4 modules** on all four sides.

```text
+------------------------------------+
|            Quiet Zone              |
|   +----------------------------+   |
|   |  [#]                  [#]  |   |
|   |         QR DATA            |   |
|   |                            |   |
|   |  [#]                       |   |
|   +----------------------------+   |
|            Quiet Zone              |
+------------------------------------+
```

### Common Design Disasters:
1. **Cropping the Border:** Graphic designers frequently trim the white space to fit tight borders. This blends surrounding artwork into the finder patterns, blinding the camera’s corner-detection algorithm.
2. **Inverting Colors:** White modules on a dark background can fail on older Android scanners. Maintain dark modules against a light background for 100% universal scan rates.
3. **Low Contrast:** Printing light gray or yellow on white destroys the binarization threshold. Always preserve high contrast (contrast ratio 4.5:1 or higher).

## Generating Secure WiFi Connection Codes

When guests visit your home, studio, or coffee shop, typing complex WPA3 alphanumeric keys causes friction. The WiFi generator mode constructs a standard MECARD-compatible payload:

```text
WIFI:T:WPA;S:StudioGuest;P:CorrectHorseBattery99;;
```

- **SSID (Network Name):** Enter the exact name, respecting uppercase and lowercase characters.
- **Security Type:** Select WPA/WPA2/WPA3 Personal, WEP, or Open.
- **Special Characters:** Semicolons, backslashes, and colons are automatically escaped by our generator.

### Data Privacy Warning:
Because the password is embedded directly into the visual pattern, anyone who photographs the QR code can decode the string. Never print access codes for sensitive internal networks; isolate guest access onto a separated VLAN before deploying printed cards.

## Exporting for Production: PNG vs Vector SVG

- **Download PNG (up to 2048x2048px):** Ideal for web pages, email signatures, presentation slide decks, and Microsoft Word documents.
- **Download SVG:** The mandatory choice for Adobe Illustrator, Figma, and commercial offset print presses. Vector paths ensure razor-sharp edges regardless of scale.

Before printing thousands of copies, always print a single physical proof and test it using both an iOS and an Android device under real-world lighting conditions.
