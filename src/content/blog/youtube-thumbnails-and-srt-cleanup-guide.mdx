Creators and content marketers constantly repurpose video assets. Two common workflows stand out: pulling the highest-resolution thumbnail artwork for promotional banners, and stripping messy timecodes from subtitle tracks to produce clean blog summaries, newsletters, or show notes.

The [YouTube Thumbnail & SRT Toolkit](/tools/youtube/youtube-toolkit/) combines these utilities into a local browser workspace. It connects directly to public image CDNs for thumbnail retrieval and sanitizes caption files locally without sending your proprietary video scripts to a remote server.

## YouTube Thumbnail Asset Architecture

YouTube stores thumbnail imagery across five standard CDN endpoints under the `i.ytimg.com` infrastructure:

| Endpoint Key | Resolution (Pixels) | Aspect Ratio | Availability / Notes |
| :--- | :--- | :--- | :--- |
| **maxresdefault** | **1280 × 720** | 16:9 HD | Available if creator uploaded custom high-res art |
| **sddefault** | **640 × 480** | 4:3 SD | Standard definition master fallback |
| **hqdefault** | **480 × 360** | 4:3 HQ | Universally generated for all public videos |
| **mqdefault** | **320 × 180** | 16:9 Widescreen | Mobile search result and recommendation tiles |
| **default** | **120 × 90** | 4:3 Small | Tiny legacy notification thumbnails |

### How to Spot Automatic Fallbacks:
If a creator never uploaded a high-resolution 1280x720 graphic, YouTube’s CDN returns a 1x1 grey transparent pixel or a scaled 120x90 fallback image for `maxresdefault`. Localtools automatically inspects the loaded natural image dimensions and alerts you if a requested size is unavailable.

## Overcoming Cross-Origin (CORS) Download Restrictions

When you click **Download JPG**, your browser attempts to fetch the remote image buffer to trigger a local file download. Occasionally, browser privacy extensions or stricter third-party CORS response headers may block automated script downloads.

When this occurs:
1. Click **Open original**.
2. The full-resolution image opens in an isolated browser tab directly from `i.ytimg.com`.
3. Right-click (or long-press on mobile) and select **Save Image As...** to preserve the full uncompressed JPEG asset.

## Cleaning SRT & WebVTT Subtitle Files

Subtitles downloaded from YouTube Studio or transcription tools contain heavy timing syntax:

```text
1
00:00:04,500 --> 00:00:08,200
Welcome back to the channel. Today we're exploring

2
00:00:08,250 --> 00:00:12,100
how client-side WebAssembly tools protect your privacy.
```

If you copy and paste this into an email newsletter or blog draft, you are left manually deleting hundreds of timestamps and line indices.

### The Cleaning Pipeline:
1. Drag your `.srt` or `.vtt` file into the **SRT / VTT cleaner** (or paste raw text).
2. The parser strips:
   - Numerical cue counters (`1`, `2`, `3`)
   - SubRip comma timestamps (`00:00:04,500 --> 00:00:08,200`)
   - WebVTT period timestamps (`00:00:04.500 --> 00:00:08.200`)
   - Positioning metadata (`line:0 position:20% align:start`)
   - HTML markup tags (`<v Speaker>`, `<b>`, `<c.color>`)
3. The tool joins fragmented phrases into cohesive, grammatically readable sentences.
